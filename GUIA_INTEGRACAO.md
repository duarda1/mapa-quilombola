# Guia de integração

Integre as partes assim que duas delas estiverem prontas:

1. Compare os nomes das entidades e campos com `docs/04_architecture/combinados.md`.
2. Confirme que os dados de exemplo cabem em `database/schema.dbml`.
3. Teste consulta e cadastro de comunidade.
4. Ligue frontend, backend e banco em pelo menos um fluxo completo.
5. Registre problemas em `EQUIPE_STATUS.md` e corrija somente o necessário para o MVP.

A demonstração mínima deve mostrar uma tela, uma requisição, uma consulta ou gravação no banco e o resultado retornando para a tela.
